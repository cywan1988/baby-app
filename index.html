📲 安装成手机APP

本软件是 PWA 应用，可像普通 APP 一样安装到桌面：独立图标、全屏运行、没有浏览器界面、二次打开离线可用。

若没出现安装按钮：
安卓 Chrome：右上角「⋮」菜单 →「添加到主屏幕」/「安装应用」；
iPhone Safari：底部「分享」→「添加到主屏幕」。

📱 手机上怎么用

手机浏览器打开摄像头必须用 https 地址（http 或双击本地文件都不行）。三个办法任选：
① 把这个 html 上传到任意免费静态托管（GitHub Pages / Cloudflare Pages / Vercel），手机访问该网址；
② 电脑上运行 cloudflared tunnel --url http://localhost:8000（或 ngrok）得到 https 链接，手机打开；
③ 只在电脑上用的话，双击本文件即可。
打开后横屏或立个手机支架对准宝宝游戏区效果最好。

建议用 Chrome / Edge 打开 · 摄像头权限仅用于本地识别 · 语音为浏览器语音合成 · 画面永不上传
